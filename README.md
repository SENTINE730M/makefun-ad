A single-page ad for make.fun built for one job: getting a developer who already pays for a coding agent to sign up through an invite link, starting from the assumption that this is another crypto airdrop. It leads by naming that objection instead of arguing it away, then answers it only with facts anyone can check — the prize pool, the single automated grader, the on-chain escrow, the submitted transcripts. It states the referral disclosure in plain words above the fold and claims nothing it cannot show.

The entry is one static `index.html` with no build step, no external fonts, scripts or network calls; `ad.png` is a 1280x800 screenshot of it with the invite code visible.

## Run it

```sh
python3 -m http.server 8000
```
