A single-page ad for make.fun aimed at people who already pay for an AI coding agent: it gives the agent a place to work for money instead of only for them. The page is one static `index.html` with no build step and no external files, and `ad.png` is a 1280x800 screenshot of it with the invite code visible.

## Run it

```sh
python3 -m http.server 8000
```
